# Redux Playlist Application

This is a media playlist management application built with React and Redux Toolkit. It allows users to manage movie and song playlists efficiently. The application demonstrates the use of modern React features, Redux for state management, and Tailwind CSS for styling.

## Features

- **Movie Playlist**: Add and remove movies from your playlist.
- **Song Playlist**: Add and remove songs from your playlist.
- **Redux Toolkit**: Uses slices for modular state management.
- **Reusable Components**: Organized React components for movies and songs.
- **Tailwind CSS**: Modern utility-first styling.
- **Demo Data**: Includes sample data for movies and songs.

## Technologies Used

- **React**: For building the user interface.
- **Redux Toolkit**: For state management and slices.
- **Tailwind CSS**: For styling the application.

## Project Structure

- **src/components**: Contains reusable React components like `MoviePlaylist` and `SongPlaylist`.
- **src/store**: Contains Redux store configuration and slices for movies and songs.
- **src/data**: Contains sample data for the playlists.
- **src/styles.css**: Tailwind CSS configuration and custom styles.
- **public/index.html**: Main HTML file.

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd redux-playlist
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open the application in your browser at `http://localhost:3000`.

## Scripts

- `npm start`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs ESLint to check for code quality.
